# Gifting Platform

A full-stack gifting platform monorepo structured into frontend and backend applications.

## 📁 Repository Structure

```
.
├── frontend/     # React + Vite + TypeScript + Material-UI application
└── backend/      # Backend service (reserved for API implementation)
```

## 🚀 Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
# Backend service setup
```
